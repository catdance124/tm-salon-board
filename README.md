# tm-salon-board

サロンボード（ネイルサロン向けSaaS）のUI改善 TamperMonkey スクリプト集。

## スクリプト一覧

| ファイル | 説明 |
|--------|------|
| [shift-inline-edit.js](shift-inline-edit.js) | シフト設定画面の各セルをクリックするとプルダウンが表示され、モーダルを開かずにシフトを直接変更できる |

## 使い方

1. ブラウザに [Tampermonkey](https://www.tampermonkey.net/) をインストール
2. 各スクリプトファイルの内容をコピーしてTampermonkeyに貼り付け
3. サロンボードにアクセスすると自動で適用される
